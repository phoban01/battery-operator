# Contributing

The working conventions (issue to branch to PR, signed commits, requirement
citations, tooling and tests) are in [CLAUDE.md](CLAUDE.md). They apply to
people and agents alike.

In short: pick an issue from the roadmap (#24), work in `devbox shell`, open
one PR that says `Closes #N` and carries the issue's `Owns:` line, and cite
every owned requirement in code and in a test
([docs/requirements/README.md](docs/requirements/README.md)).
